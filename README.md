# Murad Portfolio

Bilingual (Arabic-first, RTL) personal portfolio built with Next.js 14, React 18, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
